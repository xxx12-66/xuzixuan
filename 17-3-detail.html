17-3 商品详情

← 返回列表 GET https://dummyjson.com/products/1

核心代码：从地址栏取 id，再请求单条数据

// 1. 读取列表页传过来的 id：17-3-detail.html?id=5
var params = new URLSearchParams(location.search);
var id = params.get('id') || 1;      // 没传 id 时默认取 1

// 2. 拼接详情接口地址并请求
var res  = await fetch('https://dummyjson.com/products/' + id);
var data = await res.json();       // 3. 直接得到"单个商品对象"（不是数组）

// 4. 用对象属性填充页面
document.getElementById('title').textContent = data.title;
document.getElementById('price').textContent = data.price;

要点：① 列表页用 <a href="?id=xx"> 传参，详情页用 URLSearchParams(location.search) 解析； ② 详情接口返回的是单个对象，可直接 data.title 取值，无需遍历； ③ 图片组 data.images 是数组，可做缩略图切换。
