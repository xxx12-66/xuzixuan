18-1 · Canvas 文字震颤动画

requestAnimationFrame 逐帧重绘 · 字符随机抖动 · 鼠标靠近增强 · 点击触发冲击波

FPS 60 字符 0 幅度 8px
移动鼠标 → 局部增强　|　点击画面 → 冲击波

动画参数

实现要点

  • 用 requestAnimationFrame 每帧清屏并重绘，形成动画
  • 把文字拆成单个字符逐个绘制，每帧给每个字一个随机位移，即"震颤"
  • 用 measureText 计算每个字的宽度，实现整体水平居中
  • 鼠标靠近时按距离衰减叠加振幅，局部抖动更强
  • 点击产生随时间衰减的冲击波，所有字符向外炸开
  • 红/青双色错位叠加（色差）让画面更像"故障艺术"
  • 按 devicePixelRatio 缩放画布，保证高清屏不模糊

核心代码

// 每帧：清屏 → 逐字绘制（带随机偏移）
function draw() {
    ctx.clearRect(0, 0, W, H);

    // 每个字符：整体居中 + 随机抖动
    chars.forEach(function (c) {
        var dx = (Math.random() * 2 - 1) * amp;
        var dy = (Math.random() * 2 - 1) * amp;
        ctx.fillText(c.ch, c.x + dx, c.y + dy);
    });

    requestAnimationFrame(draw);   // 递归下一帧
}
