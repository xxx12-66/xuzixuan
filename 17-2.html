17-2 · Fetch 请求接口数据

原生 JavaScript + fetch() 调用真实 API，渲染商品列表（加载中 / 失败重试 / 筛选 / 排序 / 详情）

GET https://fakestoreapi.com/products
—

核心代码（原生 fetch）

// 1. 发起请求：fetch 返回 Promise
async function loadProducts() {
    try {
        var res = await fetch('https://fakestoreapi.com/products', { cache: 'no-store' });
        if (!res.ok) throw new Error('HTTP ' + res.status);  // 404 / 500 等

        var data = await res.json();   // 2. 响应体 → JS 数组（等价于 JSON.parse）
        render(data);               // 3. 遍历数据拼接 HTML → innerHTML
    } catch (err) {
        showError(err.message);     // 4. 断网 / 跨域 / 接口异常统一处理
    }
}

要点：① fetch 只有在网络失败时 reject，HTTP 404/500 不会自动报错，必须手动判断 res.ok； ② res.json() 是异步方法，内部就是 JSON.parse()； ③ 本接口已开放 CORS（Access-Control-Allow-Origin: *），所以浏览器允许跨域读取； ④ 若直接用 file:// 打开页面，部分浏览器会因源为 null 而拦截，建议用本地服务器访问。
