图 1 · 渐变色 阴影 点击缩放

bar-gradient 官方示例 ↗

类目为单个汉字；柱子用 LinearGradient 竖向渐变 + shadow 阴影 + 顶部圆角， 配合 showBackground 的灰底槽道。点击任意柱子可放大该区间，点击空白处恢复。

查看 option 配置 
const option = {
  title: {
    text: '特性示例：渐变色 阴影 点击缩放',
    subtext: 'Feature Sample: Gradient Color, Shadow, Click Zoom',
    left: 'center'
  },
  tooltip: { trigger: 'axis', axisPointer: { type: 'shadow' } },
  grid: { left: 55, right: 28, top: 82, bottom: 36 },
  xAxis: {
    type: 'category', data: chars,        // 每个汉字一个类目
    axisLabel: { interval: 0 },
    axisTick: { alignWithLabel: true }
  },
  yAxis: { type: 'value', min: 0, max: 500 },
  dataZoom: [{ type: 'inside', start: 0, end: 100 }],
  series: [{
    type: 'bar',
    data: values,
    showBackground: true,                 // 灰底槽道
    backgroundStyle: { color: 'rgba(0,0,0,.035)', borderRadius: 2 },
    itemStyle: {
      borderRadius: [5, 5, 0, 0],
      color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [
        { offset: 0, color: '#7cc4ff' },
        { offset: 1, color: '#2f7cf6' }
      ]),
      shadowBlur: 10,
      shadowColor: 'rgba(47,124,246,.35)',
      shadowOffsetY: 4
    }
  }]
};

// 点击柱子 → 把 dataZoom 聚焦到该区间；点空白恢复
chart.on('click', function (p) {
  const n = chars.length, span = 6;
  const s = Math.max(0, p.dataIndex - 2);
  chart.dispatchAction({ type: 'dataZoom', start: s / n * 100, end: (s + span) / n * 100 });
});

图 2 · 抖动散点图

scatter-jitter 官方示例 ↗

每个类目（Mon ~ Sun）各有一簇样本，x 坐标在 类目位置 1~7 的基础上叠加随机抖动， 让同类目的点沿水平方向自然散开而不完全重叠。悬停任意散点可查看所属类目与数值。

查看 option 配置 
// 每个类目 i 生成一簇点：[类目位置(i+1) ± 抖动, 数值]
const JITTER = 0.62;                    // 抖动幅度，1 = 一个类目宽度
const jitterData = days.map((d, i) =>
  Array.from({ length: PER_DAY }, () => [
    i + 1 + (Math.random() - 0.5) * JITTER,  // x：1~7 为类目中心
    randomY()                                 // y：0~10 的近似正态值
  ])
);

const option = {
  tooltip: { trigger: 'item' },
  grid: { left: 48, right: 26, top: 84, bottom: 32 },
  xAxis: {
    type: 'value', min: 0, max: 8, interval: 1,
    // 1~7 映射为星期名，0 与 8 留白给抖动
    axisLabel: { formatter: v => days[v - 1] || '' }
  },
  yAxis: { type: 'value', min: 0, max: 10, interval: 2 },
  series: days.map((d, i) => ({
    name: d,
    type: 'scatter',
    symbolSize: 7,
    data: jitterData[i],
    itemStyle: { color: dayColors[i], opacity: 0.7 },
    emphasis: { scale: 2 }
  }))
};

图 1 要点

  • 渐变色用 echarts.graphic.LinearGradient(0,0,0,1,...)，纵向渐变即"上浅下深"
  • showBackground: true 生成每根柱子后的灰色槽道，视觉更整齐
  • 只让顶部两角圆：borderRadius: [5,5,0,0]
  • 阴影用 shadowBlur / shadowColor / shadowOffsetY，颜色取主色的低透明度
  • 缩放：dataZoom type:'inside' + dispatchAction 实现"点击放大"

图 2 要点

  • 抖动散点的核心：x 用 类目位置 + 随机偏移，把同值重叠的点摊开
  • 类目位置从 1 起算（i + 1），与 axisLabel 的 days[v-1] 对应
  • x 轴用 type:'value' 才能接受小数坐标，类目名靠 formatter 还原
  • 轴范围留出 0 与 8 两个空白刻度，避免首尾点被裁切
  • 每个类目一个 series，颜色独立；opacity + symbolSize 控制密集区的可读性
