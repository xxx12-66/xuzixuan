18-3 · 知识库智能客服系统架构（SVG）

研究方向：基于检索增强生成（RAG）的企业知识库智能客服 —— 离线知识构建 + 在线检索推理 + 评测闭环

悬停节点查看说明 · 点击节点高亮其链路 · ★ 为研究重点

研究问题与研究点

  • 知识时效与覆盖：多源异构文档如何统一解析与增量更新（文档解析 / 语义分块）
  • 检索精度：稠密向量 + BM25 稀疏检索融合，Cross-Encoder 精排（★ 混合检索、Rerank）
  • 幻觉抑制：证据约束生成 + 段落级引用溯源，答案必须可追溯（★ 引用溯源）
  • 领域适配：通用 LLM 的 LoRA / SFT 领域微调与指令模板设计（★ LLM 底座）
  • 可评测性：构建中文客服问答基准，结合自动指标与人工双评（★ 评测基准）

评测指标与实验设计

  • 检索侧：Recall@k、MRR、nDCG@10
  • 生成侧：Answer Accuracy、Faithfulness（忠实度）、Answer Relevancy（RAGAS）
  • 系统侧：首字延迟 P95、单位请求成本、转人工率
  • 消融实验：去重排 / 去混合检索 / 去引用 四种配置对比
  • 鲁棒性：噪声文档注入、对抗提问、无答案拒答率

SVG 绘制说明

  • 整图用 <svg> 矢量绘制，缩放不失真，可直接插入论文
  • 每个节点是一个 <g class="node">，圆角矩形 rect rx="10"
  • 连线用 path 的三次贝塞尔，箭头由 marker-end 定义
  • 主题色通过 CSS 变量 var(--node) 控制，深浅色一键切换
  • 导出 SVG 时把内部 CSS 一并内联，保证单独打开也正常渲染
