Surface three.js 示例 ↗

把 PlaneGeometry 的每个顶点按高度函数抬升成起伏曲面，用 顶点色映射高度， 再叠一层 WireframeGeometry 网格线。悬停曲面可读取交点坐标与高度。

// 1. 平面网格：48×48 分段，够密才能看出起伏
const geo = new THREE.PlaneGeometry(11, 11, 48, 48);
geo.rotateX(-Math.PI / 2);          // 从 XY 平面转到 XZ 平面（水平）

// 2. 逐顶点抬高 + 按高度着色
const pos = geo.attributes.position;
const colors = [];
for (let i = 0; i < pos.count; i++) {
  const x = pos.getX(i), z = pos.getZ(i);
  const y = heightAt(x, z);            // 高斯凸包 + 正弦波纹
  pos.setY(i, y);

  const c = new THREE.Color().setHSL(0.58 - y * 0.045, 0.75, 0.55);
  colors.push(c.r, c.g, c.b);
}
geo.setAttribute('color', new THREE.Float32BufferAttribute(colors, 3));
geo.computeVertexNormals();             // 重新算法线，光照才正确

// 3. 曲面 + 网格线叠加
const mesh = new THREE.Mesh(geo, new THREE.MeshStandardMaterial({
  vertexColors: true, roughness: 0.55, metalness: 0.15, side: THREE.DoubleSide
}));
const wire = new THREE.LineSegments(
  new THREE.WireframeGeometry(geo),
  new THREE.LineBasicMaterial({ color, transparent: true, opacity: 0.16 })
);

图 1 要点

  • three.js 的最小组合：Scene + PerspectiveCamera + WebGLRenderer
  • 柱高不用重新建几何体，改 mesh.scale.y 并把 position.y 设成高度的一半
  • MeshStandardMaterial 需要光照才显色，别忘了 AmbientLight / DirectionalLight
  • 文字用 Sprite 始终朝向相机，比 3D 文字省性能
  • 相机绕原点旋转只需球坐标 (az, el, dist) 三个量，比引入控制器更轻

图 2 要点

  • 顶点位移后必须 computeVertexNormals()，否则高光和水面一样平
  • PlaneGeometry 默认在 XY 平面，rotateX(-90°) 才是水平地面
  • 顶点色要求材质开启 vertexColors: true，并写入 'color' 属性
  • 网格线单独用 WireframeGeometry，可与实体叠加而不遮挡
  • 渲染循环用 requestAnimationFrame，尺寸变化时同步 aspect 与 setSize
