架构分层说明

  • 用户层：Web 浏览器、App、小程序、运营后台，通过 HTTPS 接入
  • 接入层：CDN 静态加速 → Nginx 负载均衡 → API 网关（鉴权、限流、路由）
  • 应用层：按业务域拆分的微服务，彼此通过 RPC / HTTP 调用
  • 中间件层：Redis 缓存、Kafka 消息队列、定时任务、配置中心
  • 数据层：MySQL 主从集群、Elasticsearch、对象存储、数据仓库
  • 基础设施：K8s 容器编排、监控、日志、链路追踪

典型下单链路：用户 → 网关 → 订单服务 → Kafka → 库存服务 → MySQL， 扣减库存后用消息队列异步通知，避免超卖并削峰。

function roundRect(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y);
    ctx.arcTo(x + w, y, x + w, y + h, r);
    ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r);
    ctx.arcTo(x, y, x + w, y, r);
    ctx.closePath();
}
